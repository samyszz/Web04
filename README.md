# 🐾 PetCare Manager — Sistema de Gestão Clínica

O **PetCare Manager** é uma solução Full Stack desenvolvida para facilitar o gerenciamento de pacientes em clínicas veterinárias. O projeto foca em uma experiência de usuário (UX) acolhedora, utilizando a estética *Cozy Tech* para transformar sistemas administrativos em interfaces agradáveis e intuitivas.

## 🚀 Funcionalidades (CRUD)

- **Create**: Cadastro dinâmico de pets com validação.
- **Read**: Listagem inteligente com busca em tempo real e filtros.
- **Update**: Edição rápida via Modal com efeito *glassmorphism*.
- **Delete**: Exclusão segura com confirmação visual.

## 🎨 Design System (Cozy Tech)
- **Cores**: Sálvia (#8FA18A), Off-white (#FDFAF6) e Tons Terracota.
- **Interface**: Bordas arredondadas (35px), sombras suaves e micro-animações.
- **Ícones**: Phosphor Icons (Bold style).

## 🛠️ Tecnologias Utilizadas

### Frontend
- **Angular 19**: Componentes Standalone e Signals.
- **TypeScript**: Tipagem estrita para maior segurança.
- **CSS3**: Animações personalizadas e layouts flexíveis.

### Backend
- **Java 17 / Spring Boot 3**: Arquitetura REST robusta.
- **Spring Data JPA**: Persistência de dados simplificada.
- **H2 Database**: Banco de dados em memória para agilidade no desenvolvimento.

## ⚙️ Como executar o projeto

1. **Backend**:
   - Navegue até `/backend/demo`
   - Execute `./mvnw spring-boot:run`
2. **Frontend**:
   - Navegue até `/frontend`
   - Execute `npm install` e depois `ng serve`
   - Acesse `http://localhost:4200`
